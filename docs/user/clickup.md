# ClickUp task links

Threads can keep ClickUp tasks as references. Open the thread's right panel, choose **Linked tasks**,
then choose **Link task**. Enter the ClickUp workspace ID, task URL or ID, and task name. The first
linked task becomes the primary task; additional links are kept as context.

Select a linked task to open it in ClickUp. Use the remove button to unlink it. If you remove the
primary task, the first remaining task becomes primary. Existing links are retained when a server
upgrades to Orchestrator v2.

The current Orchestrator v2 integration stores and opens task references. It does not browse
ClickUp workspaces or fetch task details.
